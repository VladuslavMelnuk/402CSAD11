**Технології:** Java 17, Maven, JUnit 5

## Опис

Проєкт демонструє автоматизоване створення, збирання та перевірку мінімального Java-застосунку `Hello, World!`. Агент `build-engineer` оркеструє підготовку Git, структури проєкту, Maven-збірки, JUnit-тесту та кросплатформного GitHub Actions CI. Maven створює виконуваний JAR `target/hello.jar`.

## Запуск агента

Відкрийте workspace у VS Code, відкрийте Copilot Chat, виберіть агента `build-engineer` і введіть команду:

```text
/run-init
```

Команда `init` з файлу `.github/prompts/run-init.prompt.md` викликається як `/run-init` через конфлікт із вбудованою командою VS Code `/init`. Вона послідовно запускає команди підготовки й перевірки проєкту. Для окремої перевірки вже налаштованого проєкту використовуйте `/check`.

## Запуск зібраного проєкту

З кореня workspace виконайте:

```sh
java src/main/java/edu/lpnu/hello/App.java
java -jar target/hello.jar
```

Команда потребує встановленого JDK 17 або новішого та зібраного JAR. Для локальної збірки і тестів виконайте `mvn -B verify`.
