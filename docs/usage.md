# Інструкція з використання

## Запуск агента в Copilot Chat

Відкрийте workspace у VS Code, перейдіть до Copilot Chat і виберіть агента `build-engineer`.

Для повного налаштування проєкту виконайте:

```text
/run-init
```

Команда `init` з файлу `.github/prompts/run-init.prompt.md` викликається як `/run-init` через конфлікт із вбудованою командою VS Code `/init`.

Для окремої перевірки вже налаштованого проєкту виконайте:

```text
/check
```

Запускайте команди з кореня workspace. `/run-init` перевіряє Git, Java 17 або новішу та Maven, а потім виконує етапи налаштування й перевірки по черзі. Якщо передумова чи етап не пройшли, сценарій зупиняється та повідомляє про помилку.

## Локальна збірка та запуск

З кореня проєкту запустіть Maven-перевірку, включно з тестами:

```sh
mvn -B verify
```

Після успішної збірки виконайте JAR:

```sh
java -jar target/hello.jar
```

Очікуваний вивід:

```text
Hello, World!
```

## Локальний CI-скрипт

На Linux або macOS з кореня проєкту запустіть:

```sh
bash ci.sh
```

Скрипт виконує `mvn -B verify`, перевіряє наявність `target/hello.jar` і запускає його. На Windows відповідний скрипт — `ci.bat`.

## Вимоги

Для локальної збірки потрібні JDK 17 або новіший і Maven. Команди запуску агента `/run-init` та `/check` вводяться в Copilot Chat, а не в термінал.
